## 总览

本文档基于 `docs/改造计划.md` 中诊断出的 10+ 项架构缺陷，制定详细的一站式修复方案。

**所有改造 100% 基于 Agno 框架** — 不是替换框架，而是纠正当前"用了 Agno 但没用对"的核心问题：

| 问题 | 现状 | 改造后 |
|------|------|--------|
| Agent 工具挂载 | `tools=[]` 缺失 | 每个 Agent 挂载 2~4 个确定性工具 |
| 路由机制 | Chainlit 关键词硬路由 + Agno Router（两套） | 统一由 Agno `TeamMode.route` 处理 |
| Team 单例 | 每次重建 Team + Agent | 线程安全双检锁单例缓存 |
| Session 管理 | 50+ 裸字符串键 | `SessionState` dataclass 类型安全封装 |
| Chainlit 架构 | 1700+ 行巨石文件 | 分层：UI / Handler / Service |
| 线程安全 | daemon 线程 + 无锁字典 | Event 通信 + cancel 信号 |
| 容错 | 单一模型无 fallback | 熔断器 + 备用模型列表 |
| 可观测性 | 纯文本日志 | 结构化 JSON + trace_id 链路追踪 |

## 二、Agno 框架核心概念回顾

改造前必须理解的关键概念：

| 概念 | Agno API | 说明 |
|------|----------|------|
| **Agent** | `Agent(name, model, instructions, tools=[...])` | 单个 AI 智能体，通过 `tools` 参数挂载确定性函数 |
| **Tool** | `@tool` 装饰器 | 将 Python 函数暴露为 Agent 可调用的工具，Agent 自行决定何时调用 |
| **Team** | `Team(mode, members=[...], model=...)` | 多 Agent 协调层 |
| **TeamMode.route** | `Team(mode=TeamMode.route)` | 内置 RouterAgent 根据用户输入语义自动分派到最合适的 Member Agent |
| **Agent.instructions** | `instructions="你是..."` | 系统提示词，定义 Agent 职责和行为规范 |

**改造核心理念**：Agent = LLM 推理 + 工具调用；Team = 自动路由；业务逻辑 = Service 层（纯 Python）。各层职责分离。

## 三、Step 1 — P0：为 Agent 挂载 Tools

### 3.1 目标

让 FieldMappingAgent、ThreatAgent、EnumAgent 各自挂载对应的确定性工具，从"LLM 裸奔"变为 **Agent 推理 + Tool 执行**的协作模式。

### 3.2 背景

### 3.3 改动文件

|------|------|------|
| `agent/core/team.py` | **修改** | 在三个 Agent 创建时传入 `tools=[...]`，并在 instructions 中增加工具调用指引 |
| `agent/core/agent.py` | **修改**（可选） | `create_agent()` 等工厂函数增加 `tools` 形参，保持 API 一致性 |

#### instructions 追加工具调用指引

每个 Agent 的 `instructions` 需要增加如下块（以 FieldMappingAgent 为例）：

```
## 可用工具

你有以下工具可以使用（不要凭空猜测，务必调用工具获取准确结果）：

1. `field_mapping_tool(source_field, standard_fields)`:
   - 对单个字段进行标准化映射（基于编辑距离算法）
   - source_field: 待映射的源字段名（字符串）
   - standard_fields: 标准字段列表
   - 返回: 最佳匹配的标准字段名和置信度

2. `generate_mapping_table_tool(source_fields, standard_fields)`:
   - 批量映射多个字段
   - source_fields: 源字段名列表
   - standard_fields: 标准字段列表
   - 返回: 完整映射表（JSON 格式）

3. `base64_decode_tool(encoded_str)`:
   - 解码 Base64 编码的输入数据
   - 当用户输入以 "eyJ" 或类似 Base64 特征开头时优先调用

## 工作流程

1. 如果用户输入疑似 Base64 编码，先调用 base64_decode_tool 解码
2. 提取出需要映射的字段
3. 调用 field_mapping_tool 或 generate_mapping_table_tool 进行标准化
4. 将工具返回的结果整理为易读的格式呈现给用户
```

## 六、Step 4 — P1：修复 TeamManager 线程安全

### 6.1 目标

修复 `agent/core/team_web.py` 中 `run_task()` 方法的线程安全隐患。

### 6.2 当前问题

```python
# team_web.py: run_task() — 当前问题版本
def run_task(self, prompt: str, timeout: int = 300):
    result = {"success": False, "response": None, "error": None}
    def run():
        response = self.team.run(prompt)       # 可能长时间阻塞
        result["response"] = response            # ⚠ 无锁写入共享字典
        result["success"] = True
    thread = threading.Thread(target=run)
    thread.daemon = True                        # ⚠ 守护线程 — 超时后静默丢弃
    thread.start()
    thread.join(timeout=timeout)
    if thread.is_alive():
        result["error"] = f"请求超时（{timeout}秒）"
        # ⚠ 线程仍在运行，无法取消，浪费 API Token
    return result
```

### 6.3 修复方案

```python
import threading
from typing import Optional, Any

class TeamManager:
    _instance: Optional["TeamManager"] = None
    _lock = threading.Lock()
    
    # ... 单例逻辑 (__new__) 保持不变 ...
    
    def run_task(self, prompt: str, timeout: int = 300) -> dict:
        """线程安全的 Team 调用，支持超时取消信号"""
        result = {"success": False, "response": None, "error": None}
        
        response_event = threading.Event()
        cancel_event = threading.Event()
        response_container: dict = {"data": None, "error": None}
        
        def run():
            try:
                if cancel_event.is_set():
                    return
                resp = self.team.run(prompt)
                if not cancel_event.is_set():
                    response_container["data"] = resp
                    response_event.set()
            except Exception as e:
                if not cancel_event.is_set():
                    response_container["error"] = str(e)
                    response_event.set()
        
        thread = threading.Thread(target=run, daemon=False)  # 非守护线程
        thread.start()
        
        finished = response_event.wait(timeout=timeout)
        
        if finished:
            if response_container["error"]:
                result["error"] = response_container["error"]
            else:
                resp = response_container["data"]
                if resp and hasattr(resp, 'content') and resp.content is not None:
                    result["response"] = resp.content
                else:
                    result["response"] = resp
                result["success"] = True
        else:
            cancel_event.set()  # 通知线程尽快退出
            result["error"] = f"请求超时（{timeout}秒）"
            thread.join(timeout=10)  # 给 10 秒优雅退出
        
        return result
```

**改动要点：**

1. `threading.Event` 替代裸 `result` 字典，实现线程间安全通信
2. `cancel_event` 提供取消信号（虽无法中断已发出的 HTTP 请求，但可阻止结果写回）
3. 线程改为非守护（`daemon=False`），配合 `thread.join(timeout=10)` 确保优雅退出

### 7.3 详细设计

#### `services/team_service.py`:

```python
"""Agno Team 调用服务层 — 与 UI 无关，纯业务逻辑"""

import asyncio
import logging
from typing import Optional
from agent.core.team import get_team_instance

logger = logging.getLogger(__name__)


class TeamService:
    """Team 调用封装：重试、超时、Token 统计"""

    def __init__(self):
        self._team = None

    @property
    def team(self):
        if self._team is None:
            self._team = get_team_instance()
        return self._team

    async def run_with_retry(
        self,
        prompt: str,
        max_retries: int = 3,
        timeout: int = 300,
    ) -> dict:
        """
        带重试的 Team 调用

        Returns:
            {"success": bool, "content": str|None, "error": str|None, "usage": dict|None}
        """
        last_error = None
        for attempt in range(1, max_retries + 1):
            try:
                response = await asyncio.to_thread(self.team.run, prompt)
                content = response.content if response and hasattr(response, "content") else None
                usage = self._extract_usage(response)
                return {
                    "success": True,
                    "content": content,
                    "error": None,
                    "usage": usage,
                }
            except Exception as e:
                last_error = str(e)
                logger.warning(
                    "Team 调用失败 (attempt %d/%d): %s", attempt, max_retries, e
                )
                if attempt < max_retries:
                    await asyncio.sleep(2 ** (attempt - 1))

        return {
            "success": False,
            "content": None,
            "error": last_error,
            "usage": None,
        }

    def _extract_usage(self, response) -> Optional[dict]:
        """从 Agno RunResponse 提取 Token 用量"""
        # 迁移 _log_token_usage 中的提取逻辑
        try:
            if hasattr(response, "metrics") and response.metrics:
                return {
                    "input_tokens": getattr(response.metrics, "input_tokens", 0),
                    "output_tokens": getattr(response.metrics, "output_tokens", 0),
                    "total_tokens": getattr(response.metrics, "total_tokens", 0),
                }
        except Exception:
            pass
        return None

    def reset(self):
        self._team = None

import threading
from typing import Optional

_team_cache_lock = threading.Lock()
_cached_team: Optional[Team] = None


def get_team_instance() -> Team:
    """获取 Team 实例（线程安全的真正单例缓存）"""
    global _cached_team
    if _cached_team is None:
        with _team_cache_lock:
            if _cached_team is None:  # 双重检查锁定
                _cached_team = _create_team()
    return _cached_team


def _create_team() -> Team:

            enum_field_tool, extract_enum_from_logs,

import dataclasses
from dataclasses import dataclass, field
from typing import Optional, Any
import chainlit as cl

SESSION_KEY = "__session_state__"


@dataclass
class SessionState:
    """应用会话状态 — 单一数据类封装所有 Chainlit 会话字段"""

    # 文件内容
    decoded_content: str = ""

    # 日志样本
    log_samples: str = ""

    # 任务类型
    current_task_type: Optional[str] = None

    # 映射结果
    mapping_results: list = field(default_factory=list)
    mapping_data: list = field(default_factory=list)

    # 威胁分类结果
    threat_results: list = field(default_factory=list)
    threat_type_mapping: dict = field(default_factory=dict)

    # 枚举提取结果
    enum_results: list = field(default_factory=list)
    enum_mapping: dict = field(default_factory=dict)

    # Team 实例引用
    team: Optional[Any] = None

    # 配置
    config: dict = field(default_factory=dict)
    standard_fields: list = field(default_factory=list)

    @classmethod
    def get(cls) -> "SessionState":
        """从 Chainlit session 获取或创建 SessionState"""
        state = cl.user_session.get(SESSION_KEY)
        if state is None:
            state = cls()
            cl.user_session.set(SESSION_KEY, state)
        return state

    @classmethod
    def exists(cls) -> bool:
        return cl.user_session.get(SESSION_KEY) is not None

    def clear(self):
        """重置所有字段为默认值"""
        for field_name, field_def in self.__dataclass_fields__.items():
            if field_def.default_factory is not dataclasses.MISSING:
                setattr(self, field_name, field_def.default_factory())
            else:
                setattr(self, field_name, field_def.default)
```

```python
import time
from enum import Enum

class CircuitState(Enum):
    CLOSED = "closed"           # 正常工作
    OPEN = "open"               # 熔断中，拒绝请求
    HALF_OPEN = "half_open"     # 试探恢复


class CircuitBreaker:
    """简单熔断器"""

    def __init__(self, threshold: int = 5, timeout: int = 60):
        self.threshold = threshold
        self.timeout = timeout
        self.failure_count = 0
        self.last_failure_time = 0.0
        self.state = CircuitState.CLOSED

    def call(self, func, *args, **kwargs):
        if self.state == CircuitState.OPEN:
            if time.time() - self.last_failure_time > self.timeout:
                self.state = CircuitState.HALF_OPEN
            else:
                raise RuntimeError("熔断器开启，拒绝请求")

        try:
            result = func(*args, **kwargs)
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            raise e

    def _on_success(self):
        self.failure_count = 0
        self.state = CircuitState.CLOSED

    def _on_failure(self):
        self.failure_count += 1
        self.last_failure_time = time.time()
        if self.failure_count >= self.threshold:
            self.state = CircuitState.OPEN
```

import uuid
from contextvars import ContextVar

trace_id_var: ContextVar[str] = ContextVar("trace_id", default="")


def generate_trace_id() -> str:
    """生成短 trace_id"""
    return str(uuid.uuid4())[:8]


def set_trace_id(trace_id: str):
    trace_id_var.set(trace_id)


def get_trace_id() -> str:
    return trace_id_var.get() or "no-trace"

"""结构化日志配置"""

import logging
import json
from datetime import datetime, timezone
from web.middleware import get_trace_id


class StructuredFormatter(logging.Formatter):
    """JSON 格式 log formatter"""

    def format(self, record):
        log_entry = {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "level": record.levelname,
            "trace_id": get_trace_id(),
            "module": record.name,
            "message": record.getMessage(),
        }
        if record.exc_info and record.exc_info[1]:
            log_entry["exception"] = str(record.exc_info[1])
        if hasattr(record, "extra_fields"):
            log_entry.update(getattr(record, "extra_fields", {}))
        return json.dumps(log_entry, ensure_ascii=False)
