# 数据映射解析工具 - 快速上手指南

## 一、运行环境要求

### 操作系统
- Windows 7/10/11（推荐Windows 10及以上）

### Python环境
- Python 3.6+（推荐Python 3.10+）
- 支持UTF-8编码

### 硬件要求
- 内存：最低2GB，推荐4GB及以上
- 磁盘空间：最低100MB可用空间

## 二、安装步骤

### 1. 克隆或下载项目
```bash
cd d:\360\leetcode\tools
```

### 2. 安装Python依赖
```bash
pip install -r requirements.txt
```

或手动安装核心依赖：
```bash
pip install numpy==1.24.3 pandas==2.0.3 openpyxl>=3.0.0 PyInstaller>=6.0.0
```

### 3. 验证安装
```bash
python main.py
```

成功启动后将显示图形化界面。

## 三、配置项清单

### 必需配置文件
- `threat_type_config.json`：威胁类型标准化配置
- `对象.xlsx`：系统属性映射模板（功能4/5使用）

### 可选配置文件
- Excel映射模板：根据功能需求自定义
- Base64编码文件：待处理的原始配置文件

### 配置文件说明

#### threat_type_config.json
定义威胁类型的标准化映射规则，包含：
- 标准威胁类型名称
- 匹配模式（REGULAR/EQUAL）
- 默认威胁类型

#### 对象.xlsx
包含系统属性与对象的映射关系，Sheet名称为"对应关系"，列结构：
- 系统属性名称
- 字段名称
- 对象

## 四、核心功能模块说明

### 功能1：字段枚举批量处理
**文件**：`field_mapping_handler.py`

**功能描述**：
- 上传Base64编码的原始规则文件
- 上传Excel格式的字段映射模板
- 解析JSON配置并提取simEntities数组
- 根据索引路径定位并修改字段值
- 自动填充threat_type字段的映射关系
- 输出修改后的配置（支持JSON格式）

**操作流程**：
1. 点击"字段枚举批量处理"按钮
2. 选择Base64编码文件
3. 选择Excel映射模板文件
4. 输入与Excel sheet名称对应的字段名
5. 点击"处理数据"按钮
6. 下载处理后的文件

**依赖**：`ThreatTypeManager`（威胁类型标准化）

### 功能2：Base64错误处理
**文件**：`base64_error_handler.py`

**功能描述**：
- 后台线程处理Base64编码数据
- 解码Base64数据并修复JSON格式错误
- 重新编码并保存处理结果
- 提供实时状态日志

**操作流程**：
1. 点击"base64错误处理"按钮
2. 选择Base64编码文件
3. 点击"删除base64字段"按钮
4. 等待处理完成
5. 下载处理后的文件

**技术特点**：
- 使用多线程避免界面卡顿
- 自动检测并修复JSON格式错误
- 支持大文件处理

### 功能3：CSV格式转换
**文件**：`feature3_handler.py`

**功能描述**：
- CSV文件上传和预览
- 自动检测文件编码
- CSV数据转换为JSON行格式
- 数据分析和统计

**状态**：开发中

**注意事项**：
- 当前功能未完全实现
- 建议使用其他工具完成CSV转换

### 功能4：标准字段映射
**文件**：`standard_field_mapping_handler.py`

**功能描述**：
- 上传原始解析规则文件（Base64编码的JSON配置）
- 上传标准字段映射表Excel文件
- 自动读取"对应关系"表建立字段与对象的映射
- 智能处理多对象情况（默认取第一个）
- 自动将新实体添加到simEntities数组
- 保存修改后的解析规则

**操作流程**：
1. 点击"标准字段映射"按钮
2. 上传原始解析规则文件
3. 上传标准字段映射表Excel文件
4. 系统自动从"对应关系"Sheet读取映射关系
5. 点击"应用映射规则"执行字段映射
6. 点击"保存解析规则"导出处理结果

**依赖**：`对象.xlsx`（系统属性映射模板）

### 功能5：字段映射集合
**文件**：`feature5_mappingall.py`

**功能描述**：
融合功能1（带枚举的字段映射）和功能4（标准字段映射）的综合功能：
1. 上传原始Base64编码的解析规则
2. 上传包含多个Sheet的字段映射模板（Sheet名称=原始字段名）
3. 可选：配置字段映射（原始字段名→标准字段名）
4. 遍历每个Sheet进行映射处理
5. 自动管理simEntities数组中的实体
6. 保存修改后的规则

**操作流程**：
1. 点击"字段映射枚举集合"按钮
2. 上传原始解析规则文件
3. 上传映射模板Excel文件
4. 可选：配置字段映射
   - 手动输入原始字段名和标准字段名
   - 或点击右侧常用字段名快捷按钮快速填充
5. 点击"处理映射"按钮执行处理
6. 点击"保存结果"按钮导出结果

**技术特点**：
- REGULAR类型映射自动添加.*前缀和后缀
- threat_type字段自动标准化
- 支持重复字段名检测和警告
- 智能判断Sheet名称是否为系统属性名

**依赖**：`对象.xlsx`、`threat_type_config.json`

## 五、关键参数说明

### 索引路径（Index Path）
- 默认值：`content.sessionproto`
- 用途：指定JSON数据中目标字段的位置
- 格式：使用点号分隔的路径，如`content.sessionproto`

### 映射类型（Mapping Type）
- `replace`：精确匹配替换
- `add`：精确匹配添加
- `REGULAR`：正则表达式匹配（自动添加.*前缀和后缀）

### 威胁类型匹配模式
- `REGULAR`：正则表达式匹配（支持模糊匹配）
- `EQUAL`：精确匹配

### 默认威胁类型
- 默认值：`其他`
- 用途：当无法匹配到标准威胁类型时使用

## 六、潜在风险及规避

### 1. Base64编码错误
**风险**：Base64编码文件格式不正确导致解码失败

**规避措施**：
- 确保Base64编码文件为纯文本格式
- 使用功能2的Base64错误处理功能自动修复
- 处理前备份原始文件

### 2. Excel格式错误
**风险**：Excel文件Sheet结构不符合要求

**规避措施**：
- 严格按照模板格式创建Excel文件
- 使用程序提供的模板下载功能
- 检查Sheet名称和列结构是否正确

### 3. 威胁类型映射失败
**风险**：威胁类型无法匹配到标准名称

**规避措施**：
- 检查`threat_type_config.json`配置是否完整
- 确认威胁类型匹配模式设置正确
- 使用模糊匹配功能（REGULAR模式）

### 4. JSON格式错误
**风险**：Base64解码后的JSON格式不正确

**规避措施**：
- 使用功能2的JSON修复功能
- 检查原始JSON文件格式
- 确保JSON字符串编码正确（UTF-8）

### 5. 大文件处理性能
**风险**：处理大文件时界面卡顿或内存不足

**规避措施**：
- 使用多线程处理（功能2已实现）
- 分批处理大文件
- 确保系统内存充足

## 八、常见问题排查

### Q1：程序启动失败
**可能原因**：
- Python版本不兼容
- 依赖库未安装

**解决方案**：
```bash
# 检查Python版本
python --version

# 重新安装依赖
pip install -r requirements.txt
```

### Q2：Base64解码失败
**可能原因**：
- Base64编码格式不正确
- 文件编码问题

**解决方案**：
- 使用功能2的Base64错误处理功能
- 检查文件是否为UTF-8编码
- 确认Base64字符串格式正确

### Q3：威胁类型映射为"其他"
**可能原因**：
- 威胁类型配置不完整
- 匹配模式设置错误

**解决方案**：
- 检查`threat_type_config.json`配置
- 确认使用REGULAR模式支持模糊匹配
- 添加缺失的威胁类型配置

### Q4：Excel文件读取失败
**可能原因**：
- Excel文件格式不支持
- Sheet结构不正确

**解决方案**：
- 使用.xlsx格式（推荐）
- 检查Sheet名称和列结构
- 使用程序提供的模板下载功能

### Q5：处理结果不正确
**可能原因**：
- 索引路径设置错误
- 映射规则配置错误

**解决方案**：
- 检查索引路径是否正确
- 验证Excel映射规则格式
- 查看日志输出定位问题
