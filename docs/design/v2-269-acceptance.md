## 人工联合验收步骤

与 #270 等 V2 切片一起在同一集成工作树验收。先记录该树的绝对路径、分支与完整 HEAD，确认端口及服务日志归属该树，再使用全新浏览器会话。

1. 以普通用户建立两个会话，各发起至少一个 Task/Run；在「我的任务」「我的执行」中切换全部、排队、运行、等待确认、成功、失败、取消中、已取消筛选，核对状态徽章、空态和分页。
2. 从两页分别点「回到原会话并查看执行」，核对会话、Run 抽屉、原消息定位；右侧同一时刻只出现一个抽屉，初始为关闭状态。
3. 对失败 Run 从抽屉重新执行，确认新 Run 沿用原冻结输入，旧失败 Run 仍在历史中。对本人进行中的 Run 执行取消确认，核对取消中与终态；切换另一个用户，确认无法查看或操作前一用户的 Task、Run、Artifact。
4. 打开有上游血缘的旧版与新版产物，核对版本、来源产物 ID、过期状态、内容预览及现有下载文件名。下载成功后查管理员审计；模拟损坏 Blob 时应拒绝下载且不新增成功下载审计。
5. 在窄窗口与深色主题下检查历史列表、状态徽章、固定 Composer、抽屉焦点和导航；离线或接口失败时仅列表显示局部错误。
