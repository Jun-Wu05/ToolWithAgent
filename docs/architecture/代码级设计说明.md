## 2. 核心类与函数

### 2.1 独立规划器（agent/core/planner.py）
PlannerService.plan() 是所有自然语言业务请求的唯一理解入口，失败时只返回安全追问。

### 2.2 熔断器 (`agent/core/resilience.py`)
`CircuitBreaker` - 状态机：CLOSED → OPEN → HALF_OPEN → CLOSED
`ModelFallback` - 主模型失败自动切换备用模型
`RetryPolicy` - 指数退避重试（max_retries=3, base_delay=2s）

### 2.3 会话状态 (`web/session_state.py`)
`SessionState` - 单例模式，管理用户会话数据（文件状态、结果缓存）

### 2.4 专业 Agent 注册表（agent/core/team.py）
create_data_mapping_team() 创建不可自主路由的专业 Agent 注册表，由执行适配器按步骤类型选择成员。

### 2.5 Prompt 加载器 (`agent/core/prompts.py`)
从 `agent/prompts/*.md` 加载 LLM Prompt 模板

### 2.6 统一 Planner 与执行核心

- `agent/core/planner.py`：无业务工具的 PlannerAgent，输出严格 `PlanDecision`。
- `web/session_facts.py`：集中投影 session 事实，不暴露密钥、路径和原始载荷。
- `web/plan_executor.py`：校验、依赖账本、停止规则和结果验证；不依赖 Chainlit。
- `web/execution_adapters.py`：连接专业 Agent 与领域函数，不接收用户原文猜参。
- `web/plan_renderer.py`：统一渲染澄清、帮助或一次执行汇总。

### 2.7 日志解析管道 (`agent/tools/log_parser_pipeline.py`)
`identify_log_format()` - Step 1：识别日志格式
`classify_log_features()` - Step 3：分类日志特征
`run_log_parser_pipeline()` - 主入口：运行完整管道（Step 1-4）

## 3. 关键算法

### 3.1 字段映射
`Qwen3-Embedding-8B 向量检索 + 中文同义词桥接`，支持驼峰规范化、精确匹配(compact key)回退、Layer1 中文索引

### 3.2 Base64 检测
`Try-Decode + JSON 验证`，尝试 Base64 解码并验证 JSON 结构

### 3.3 熔断器状态机
`CLOSED → OPEN → HALF_OPEN → CLOSED`，线程安全保护

### 3.4 日志解析管道
`格式识别 → 正则聚合 → 特征分类 → 指纹存储`，4 步 Pipeline

---

## 4. 错误处理

**三层防护**：RetryPolicy（局部重试）→ CircuitBreaker（进程级熔断）→ ModelFallback（Provider 切换）

**工具层**：所有外部调用（API、文件 I/O、子进程）均有 `try-except` 包裹在具体异常类型上

---

## 5. 配置

`config/route_keywords.json` - 路由关键词（日志解析、威胁、枚举等）
`config/threat_type_config.json` - 威胁类型映射配置

---

## 6. 数据流

详见：chainlit_app模块说明.md

**字段映射**：用户 + SessionFacts → PlannerAgent → PlanExecutor → FieldMappingAgent → Renderer
**威胁填充**：用户 → PlannerAgent → ThreatAgent → 本次依赖账本 → FillAdapter → Renderer
**日志解析**：日志行 → 格式识别 → 正则聚合 → 特征分类 → 指纹存储 → 渲染

---

## 7. 编码规范

- 类型提示：所有新函数必须有类型注解
- 错误处理：外部调用必须有 `try-except` 且指定具体异常类型
- 日志：使用 `agent.shared.logger.get_logger()` 统一日志
- 导入排序：标准库 → 第三方 → 本地
- 变量命名：使用显式名称，避免无上下文变量
- Prompt 管理：从 `agent/prompts/*.md` 文件加载
