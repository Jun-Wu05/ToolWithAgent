> **文档版本**：2026-08-31

## 1. 包依赖

```text
web/ ───────────────> application/ ───────────────> contracts/
                         │
                         ├── adapters/ ────────────> agent/ + skills/
                         ├── model_runtime.py ─────> agent/core/
                         ├── field_runtime.py ─────> agent/core/field_retriever.py
                         └── request_runtime.py ───> agent/core/planner.py

agent/core/field_retriever.py ─────────────────────> agent/core/standard_field_catalog.py

agent/ ────────────────────────────────────────────> contracts/
```

- `contracts/` 只定义类型化契约和不变量，不读取运行时会话。
- Application 核心（execution、session、progress）不依赖 Chainlit、Agno 或具体领域实现。
- Application Adapters 是领域接缝，可以依赖 Agent、Pipeline、共享领域函数和 Skills。
- Web 只依赖 Application 公共入口；Application、Contracts、Agent 和 Skills 禁止导入 Web。

## 2. Application 核心

### 2.1 请求运行时

`application/request_runtime.py` 提供两个公共入口：

- `run_user_request(...)`：投影 SessionFacts、调用 Planner 一次、组合 Adapter 与 PlanExecutor、执行并写入受限历史。
- `run_deterministic_plan(...)`：执行按钮等已经类型化的计划，不调用 Planner。

精确清空命令由同一模块确定性处理。它是唯一允许绕过 Planner 的文本事件。

### 2.2 执行运行时

`application/execution.py` 定义 `ExecutionContext`、`StepAdapter`、`ExecutionPolicy` 和 `PlanExecutor`。PlanExecutor 只负责：

1. 校验步骤结构、Session 事实与依赖；
2. 按顺序分派 StepAdapter；
3. 保存本次计划结果账本；
4. 验证步骤结果；
5. 遇到 failed 或 needs_input 后停止；
6. 返回一个 ExecutionReport。

`application/execution_policy.py` 承载分类特征字段、固定字段和目标范围等领域预检，避免污染通用执行器。

### 2.3 会话与历史

`application/session_state.py` 定义 `PrimaryDatasetSnapshot` 和 `SessionState`。新的有效主数据原子替换旧主数据，并清理附件、派生配置和可引用会话产物；无效上传不改变现有状态。

`application/session_projection.py` 是 SessionState → SessionFacts 的单一实现，只暴露计数、字段名、配置来源和安全产物目录。字段投影分为 Planner 点名词典 `available_fields` 与映射执行池 `mappable_fields`：前者保留标准名以支持显式填充目标；后者在纯上传配置路径排除 `normalize[].field` 非空的 index，并携带上传配置已映射/未映射计数，供 PlanExecutor 和 FieldMappingAdapter 共用。`mappings` 是否非空不参与字段映射状态判定。`application/history.py` 保存有限用户/助手文本，不把配置、枚举真实值或模型完整输出写入 Planner 上下文。

### 2.4 基础运行时

| 模块 | 公共职责 |
|---|---|
| `application/model_runtime.py` | API key 解析、设置应用、Team 懒初始化与重置 |
| `application/field_runtime.py` | 字段缓存初始化与候选检索公共入口 |
| `application/file_input.py` | Base64/JSON/TXT 解码、简化数据与主数据原子提交 |
| `application/progress.py` | 无 UI 场景的 NullProgressSink |
| `application/parsing.py` | 专业 Agent 结构化结果解析 |
| `application/artifact_targets.py` | 配置标准字段收集和唯一目标绑定 |
| `application/enum_mapping_attachments.py` | 枚举映射附件提交与过期状态维护 |

## 3. Application Adapters

`application/adapters/composition.py::create_default_adapters(team)` 是唯一生产组合入口，注册 12 类 StepSpec：

- log_parse、field_mapping、enum_extract、threat_mapping；
- fill（内部按 enum/threat 分派）、remove_mapping、export；
- add_fields、delete_fields、merge_fields、base64_decode_fields、regex_extract_field。

Adapter 只把类型化参数翻译为领域调用，发布安全进度，构造 Artifact，并在全部校验成功后一次性写回 Session。它不理解用户原文，也不从未声明的 Session 键寻找替代输入。

`application/field_mapping_batch.py::FieldMappingBatchRunner` 集中字段映射的分批、并发、超时拆批、重试、Retry-After、漏字段补查、去重与顺序恢复。FieldMappingAdapter 只消费 SessionFacts 的 `mappable_fields`，并负责产物、事件名称标注和原子提交；不再从 Planner 点名词典推导映射输入。上传 `decoded_data` 的写回层会保护已有非空 field 条目的 `field/entity/sim/core`，全部已映射时直接返回零模型调用成功；由系统生成的 `mapped_sub_rules` 仍执行全量重映射并明确提示覆盖。

## 4. Agent 与领域实现

- `agent/core/planner.py`：无业务工具的 PlannerAgent，输出严格 PlanDecision。
- `agent/core/team.py`：专业 Agent 注册表，不自主路由用户请求。
- `agent/core/model_config.py`：ProviderSpec 注册表和模型构造。
- `agent/core/standard_field_catalog.py`：只读标准字段 schema、资源解析、名称/别名 lookup 与确定性索引。
- `agent/core/field_retriever.py`：标准字段 embedding、缓存、排除与候选排序策略；标准字段事实委托 Catalog。
- `agent/tools/pipeline/`：日志格式识别、特征定位、分类和样本回填。
- `agent/tools/rule_generator/`：入口规则、子规则、filter 与 normalize 生成。
- `agent/shared/`：字段/值映射、事件名称标注、正则与日志等共享领域逻辑。
- `agent/prompts/`：全部 Prompt 文件与公开加载器；标准字段文本通过 Catalog 的只读资源边界返回。
- `skills/*/scripts/`：字段调整确定性变换的单一事实源。

## 5. Web 适配层

Web 不拥有 Planner、执行器、Session、历史、Adapter、模型配置或字段检索实现：

- 生命周期：`chainlit_app.py`、`start_handler.py`、`settings_handler.py`；
- 消息与文件：`message_router.py`、`file_handlers.py`、`user_message_handlers.py`；
- 确定性事件：`action_callbacks.py`、`deterministic_plan.py`；
- 展示：`chainlit_progress.py`、`plan_renderer.py`；
- Chainlit 辅助：`file_handler.py`、`parsers.py`、`utils.py`、`llm_client.py`。

## 6. 稳定不变量

- 自然语言请求恰好一次 Planner 调用；确定性入口零 Planner 调用。
- Adapter 组合入口唯一，StepSpec 参数自包含。
- SessionFacts 不包含密钥、真实路径或原始敏感值。
- 模型调用阶段、批大小、并发、超时、重试与补查策略不因物理迁移变化。
- 配置来源、JSON/Base64 字节、下载文件名、稳定错误码与 Chainlit 交互保持兼容。
- Prompt 与 Skill 资源按包/脚本位置定位，支持从非仓库工作目录启动。
