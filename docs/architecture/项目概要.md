# ToolWithAgent 智能体系统 — 项目概要

> 本文是面向新读者的当前架构摘要;分层细节见 `架构概览.md`,领域词汇见根目录 `CONTEXT.md`,
> 历史决策见 `docs/adr/`。旧版本文所描述的关键词硬路由架构已随 ADR-0005 统一 Planner 架构退役。

## 目标

基于 LLM 的智能体系统,通过 Chainlit Web 界面帮助安全分析人员完成日志解析、字段映射、
枚举提取、威胁类型分类与规则导出等任务。

## 技术栈与核心形态

- **语言**: Python 3.10+;**前端**: Chainlit Web 框架
- **规划**: 独立 PlannerAgent(`agent/core/planner.py`)负责理解自然语言指令并产出类型化计划;
  专业 Agent 注册表(`agent/core/team.py`)只供执行适配器按步骤类型选择成员,无自主路由
- **执行**: 统一 PlanExecutor(`application/execution.py`)按类型化步骤分派适配器,
  含有界自恢复重试(ADR-0011)
- **会话**: `SessionState`(`application/session_state.py`)类型化数据类,属性直读直写,
  由 `web/start_handler.py` 在会话开始时装配;安全事实投影经 `build_session_facts` 供 Planner 使用
- **提示词**: Markdown 文件集中管理(`agent/prompts/`),动态加载,无硬编码回退

## 当前能力

1. **文件上传与解析** — Base64/文本/Excel 上传,原子提交主数据快照到会话
2. **日志类型提取** — 格式识别→特征定位→分类→样本回填的确定性 Pipeline
3. **标准字段映射** — 批处理字段映射(超时拆批、并发、补查)、目录合法性校验、事件名称标注
4. **枚举提取与填充** — 正则生成 + 枚举映射表管理,填充贡献账本与过期状态
5. **威胁类型链路** — 来源候选检索、映射、固定目标填充、原子提交(含自动改选重跑)
6. **规则导出** — 入口/子规则/映射后子规则多形态导出,数据源字段统一守卫
7. **统一 Planner 架构** — 意图理解、类型契约、执行器与渲染器职责分离(ADR-0005)

## 关键入口

| 文件 | 作用 |
|------|------|
| `web/chainlit_app.py` | 薄入口,仅生命周期钩子 + 转发 |
| `web/start_handler.py` | 会话开始装配 SessionState |
| `web/message_router.py` | 消息路由分发(per-session 锁) |
| `web/user_message_handlers.py` | 自然语言入口(Planner 恰好一次) |
| `application/request_runtime.py` | 统一请求运行时(计划确认/执行/威胁链续跑) |
| `application/execution.py` | PlanExecutor 与类型化 ExecutionContext |
| `agent/core/planner.py` | 独立 PlannerAgent 与失败关闭策略 |
| `agent/prompts/planner.md` | 统一意图理解与计划输出约束 |
