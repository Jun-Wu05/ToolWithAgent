# ADR-0006：可引用会话产物

- 状态：已接受
- 日期：2026-08-20
- 关联：补充 ADR-0005；Issue #80

## 背景

ADR-0005 禁止专业 Agent 和执行器隐式读取旧 `last_*` session 键，确保每个步骤的输入都能从类型化计划审计。但枚举提取和威胁映射的结果只在本次计划账本中可依赖；结果表格已经展示后，下一轮“做威胁映射”或“填充回去”没有合法来源，只能追问或重复执行。

把完整旧结果写入对话历史会向 Planner 暴露原始业务值；重新允许适配器读取 `last_*` 又会恢复隐式兜底。两者都破坏 ADR-0005 的角色边界。

## 决策

引入隶属于当前主数据的**可引用会话产物**。首版分别保存最近一次成功的枚举值产物和威胁映射产物，并通过两个白名单来源引用：

- `session.artifacts.enum_values`
- `session.artifacts.threat_mapping`

真实产物只保存在类型化 Session 槽位中。`SessionFacts` 仅向 Planner 暴露安全目录：产物类型、数量、来源字段，以及每个可用配置来源对应的唯一标准目标字段；不得包含真实枚举值、威胁映射行或配置内容。Planner 负责根据用户原文和有限历史选择显式来源，Executor 和 Adapter 负责再次校验产物存在性、类型及目标字段绑定。

成功步骤覆盖同类最近产物；失败或待输入步骤不覆盖。两个产物类型相互独立。新的有效主数据原子替换或清空命令清除全部可引用会话产物；无效上传、枚举映射附件变化和其他操作不使其失效。

有来源字段的威胁产物只能填回当前配置中由该字段唯一映射出的非空 `normalize.field`。没有来源字段的直接值威胁产物，只有用户在后续请求中明确指定当前配置内合法标准字段时才可填充。

> **2026-09-02 修订（#173 / ADR-0010）**：上段的血缘推导填充目标已被取代——威胁映射
> 产物的填充目标现在固定为「威胁类型」（字段映射改判会使血缘静默漂移到无关字段），
> 目录 `target_bindings` 仅在配置已含威胁类型条目时发布该固定绑定；直接值产物的
> "用户显式指定任意合法标准字段"同样收敛为固定目标 + Planner 澄清。其余不变量不变。

## 公共不变量

- 遗留 `last_enum_extract_result` 与 `last_threat_data` 继续只服务展示和兼容计数，绝不自动升级为执行产物。
- session 产物来源不得同时携带本次步骤依赖或直接 values。
- 跨轮威胁填充必须声明唯一目标字段和可用 `config_ref`。
- Planner 只看到安全目录；Executor 不理解用户原文；Adapter 不从其他 session 键寻找替代输入。
- 计划生成后若产物被清除、损坏或目标字段不再唯一，执行必须以稳定错误码安全停止。

## 取舍

Session 中会同时保留展示用旧结构与执行用类型化产物，短期存在少量重复数据；换取的是不破坏现有按钮与表格的兼容迁移。首版只保留每种类型最近一次成功产物，不支持按字段回选更早结果；多字段历史选择由后续 Issue #108 单独设计。
