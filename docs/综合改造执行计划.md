## Phase 3：性能优化（针对 5.5 分钟延迟）

### 3.1 LLM 调用加超时保护

**文件**：`web/llm_client.py`  
**位置**：`call_team()` 函数内 `asyncio_mod.to_thread(team.run, ...)` 调用处

**当前代码**（约 LXX 行）：
```python
result = await asyncio_mod.to_thread(team.run, user_input)
```

**修改为**：
```python
import asyncio

try:
    result = await asyncio.wait_for(
        asyncio_mod.to_thread(team.run, user_input),
        timeout=120.0  # 2 分钟超时
    )
except asyncio.TimeoutError:
    logger.error("[llm_client] Team run 超时（120s），返回降级响应")
    return "[System] 请求处理超时，请稍后重试或简化输入内容。"
```

### 3.2 关键词预筛跳过 RouterAgent

**文件**：`web/llm_client.py`  
**位置**：`call_team()` 函数开头

**当前代码**：
```python
async def call_team(user_input: str, session_id: str = "") -> str:
    team = get_team_instance(session_id)
    result = await asyncio_mod.to_thread(team.run, user_input)
    ...
```

**修改为**：在调用 `team.run()` 之前，先做关键词预筛，命中则直接路由到对应 Agent

```python
from web.route_config import ENUM_KEYWORDS, THREAT_KEYWORDS

async def call_team(user_input: str, session_id: str = "") -> str:
    team = get_team_instance(session_id)
    
    # 关键词预筛：命中枚举/威胁则加入路由提示，减少 RouterAgent 推理时间
    lower_input = user_input.lower()
    if any(kw in lower_input for kw in ENUM_KEYWORDS):
        user_input = f"[ROUTE_HINT: 枚举处理] {user_input}"
    elif any(kw in lower_input for kw in THREAT_KEYWORDS):
        user_input = f"[ROUTE_HINT: 威胁类型] {user_input}"
    
    result = await asyncio.wait_for(
        asyncio_mod.to_thread(team.run, user_input),
        timeout=120.0
    )
    ...
```

### 3.3 优化 Prompt 中的标准字段表注入方式

**文件**：`agent/core/team.py`  
**位置**：`_get_field_mapping_instructions()` 函数（约 L61-80）

**当前代码**（L61-75）：
```python
def _get_field_mapping_instructions() -> str:
    prompts = _load_prompts()
    standard_fields = _load_standard_fields_list()
    
    return f"""你是网络安全日志标准化专家。

{prompts['field']}

## 标准字段表（必须严格使用以下中文名称）
```
{standard_fields}
```

注意：
- 必须严格按照上述规则输出
...
```

**修改为**（在标准字段表前后加认知负载声明）：
```python
def _get_field_mapping_instructions() -> str:
    prompts = _load_prompts()
    standard_fields = _load_standard_fields_list()
    
    return f"""你是网络安全日志标准化专家。

{prompts['field']}

## 标准字段表（参考字典 — 匹配时按需查询，无需逐条记忆）
```
{standard_fields}
```

## 字段匹配策略
- 将标准字段表视为参考字典，仅当需要匹配某字段时才在表中查找
- 匹配方式：将用户字段名与标准字段表逐行对比，取最相似的中文系统属性名称
- **禁止**：试图理解或记忆全部标准字段，只关注当前需要匹配的字段

注意：
- 必须严格按照上述规则输出
- **只输出 JSON 数组格式的映射结果**，不输出解释、分析、过程或备注
- JSON 格式必须为：`[{{"原始字段名": "xxx", "系统属性名称": "yyy", "匹配状态": "匹配成功"}}]`
- 只能使用标准字段表中的中文系统属性名称
```

**原理**：LLM 看到 654 行字段表时会产生"需要全部记忆"的认知压力 → 声明为"参考字典"可降低这层负担，减少不必要的推理时间。
