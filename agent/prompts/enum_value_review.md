## 任务：标准枚举值归类（第二阶段）

第一阶段已把原始字段映射到标准枚举字段。下面给出该字段在某个日志类型中的
**全部唯一非空值**（代码全量扫描得到，不多不少），你需要把每个值归类到
目标标准字段的**白名单标准值**上。

## 硬约束

1. **每个输入值必须且只能输出一行**：`原始字段名` 填输入原值本身（逐字保留，
   不翻译、不改大小写、不去空格），`系统属性名称` 填白名单内的标准值。
2. `系统属性名称` **只能取自本次输入给出的白名单**，严禁自造值、严禁输出英文列。
3. 语义兼容但无法可靠归类的值，选择输入中给出的**默认值**。
4. 若值域整体与目标标准字段不兼容（值的语义明显属于另一类字段，
   例如动作字段的值是 success/failed 这类结果语义），所有行输出 `未匹配`。
5. 禁止新增输入中不存在的值、禁止遗漏或合并任何输入值。
6. 只输出 JSON 数组，不输出解释或其他字段。
