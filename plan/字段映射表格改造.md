# 字段映射表格改造计划

## 改造概述

将Markdown表格改为 `cl.Dataframe` 数据表格，提供企业级交互体验。

## 已完成改造

### 1. Agent输出格式修改

**修改文件：**
- `agent/prompts/field_weak.md` - 提示词文件
- `agent/core/team.py` - Team配置

**改造内容：**
- Agent输出格式从 Markdown 表格改为 JSON 数组
- JSON 格式：
```json
[
  {"原始字段名": "xxx", "系统属性名称": "yyy", "匹配状态": "匹配成功"},
  {"原始字段名": "aaa", "系统属性名称": "未匹配", "匹配状态": "未匹配"}
]
```

### 2. Chainlit界面改造

**修改文件：**
- `web/chainlit_app.py` - Chainlit应用

**改造内容：**

#### 2.1 JSON解析功能
- `parse_json_mapping_result()` - 解析Agent返回的JSON映射结果
  - 支持多种JSON格式识别（纯JSON、代码块包裹等）
  - 验证数据格式有效性

#### 2.2 DataFrame表格展示
- `create_dataframe_elements()` - 创建Chainlit元素
- 使用 `cl.Dataframe` 组件展示映射结果
- 支持排序和筛选功能（内置支持）

#### 2.3 Excel导出功能
- 自动生成Excel文件
- 使用 `cl.File` 元素提供下载
- 文件名格式：`字段映射表_YYYYMMDD_HHMMSS.xlsx`

#### 2.4 一键复制功能
- 提供JSON文件下载
- 在消息中展示可复制的JSON代码块
- 支持直接复制

### 3. 功能统计

**表格展示内容：**
- 总字段数
- 匹配成功数
- 未匹配数

**交互功能：**
- ✅ 排序（点击列标题）
- ✅ 筛选（内置筛选功能）
- ✅ Excel导出（下载按钮）
- ✅ 一键复制（JSON文件 + 代码块）


## 注意事项

1. Agent返回的JSON必须严格遵循格式：`[{"原始字段名": "...", "系统属性名称": "...", "匹配状态": "..."}]`
2. 如果JSON解析失败，将回退到直接输出原始内容
3. Excel导出需要 `openpyxl` 库支持
