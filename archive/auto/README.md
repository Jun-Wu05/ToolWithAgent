# auto 目录说明

本目录用于字段映射、日志提取和分阶段数据处理。

## phase1
- 作用：解析原始索引数据，生成标准化索引结果。
- 主要输入：原始解析文件、索引数据文件。
- 主要输出：`normalize_indexes.txt` 等中间结果。

## phase2
- 作用：根据原始日志、索引结果和标准字段说明，生成标准字段映射表。
- 主要输入：原始日志 JSON、`normalize_indexes.txt`、`标准字段说明.txt`。
- 主要输出：标准字段映射结果文件、字段映射中间文件。

## phase3
- 作用：按字段键和正则从 `data/` 下的日志文件中逐行提取非重复值，并生成分组重排结果。
- 主要输入：`data/` 下的日志文件、字段 key、正则表达式。
- 主要输出：`output/` 下的提取结果文件、mapping 文件、分组重排文件。
- 说明：当前脚本会自动遍历 `data/` 下每个文件，并为每个输入文件生成独立输出。
- 说明：正则支持直接回车使用默认值，默认格式兼容空格可选、单双引号。
- 说明：重排文件按字段值分组聚合，组首写字段值，组尾写 `==========`。
- 说明：未匹配行会放到最后的 `未匹配` 分组中。

## 目录约定
- `data/`：阶段输入数据或中间数据。
- `output/`：阶段输出结果。
- `提示词.md`：阶段 2 的提示词模板。
- `field.py`：阶段 3 的批量提取脚本。

## 使用建议
- 先在 `phase1` 生成规范索引，再进入 `phase2` 做字段映射。
- `phase3` 适合对日志文件批量抽取字段值并生成映射模板。
- 所有输出建议统一写入各自 `output/` 子目录，避免覆盖。
